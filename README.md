# elitedangerous_file_explorer
Python code for decompressing and decrypting the Win64/ directory of Elite Dangerous.  This gives you access to multitudes of files (textures, sounds, strings and more).

# How to use:
Run the frea_explorer.py using pythong.  ```python frea_explorer```
